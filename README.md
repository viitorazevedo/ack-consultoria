# ACK Consultoria

Site institucional da ACK Consultoria LTDA. HTML estático publicado no GitHub Pages.

## Publicar

1. Settings → Pages → Deploy from a branch → `main` / `(root)`
2. Custom domain: o domínio do arquivo `CNAME`, com "Enforce HTTPS" marcado
3. Fluxo completo de edição, validação e deploy: `.claude/skills/ack-consultoria/SKILL.md`
